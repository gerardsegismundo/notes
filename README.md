## Exam Domains Covered

- **Domain 1:** Design resilient architectures (high availability, fault tolerance)
- **Domain 2:** Design high-performing architectures (scalability, caching)
- **Domain 3:** Design secure architectures (IAM, encryption, network isolation)
- **Domain 4:** Design cost-optimized architectures (storage tiers, compute models)

## Study Approach

1. Read through each topic file systematically
2. Mark concepts as understood in the checklist at the end of each file
3. Practice with exam scenarios in the reference matrices
4. Review key architectural patterns and trade-offs

## Quick Reference Keywords

- **High Availability:** Multi-AZ, Read Replicas, Failover, RDS
- **Serverless:** Fargate, Lambda, S3, DynamoDB
- **Security:** IAM roles, KMS, SSM, VPC Endpoints, WAF
- **Scalability:** Auto Scaling, ELB, Sharding, Partitioning
